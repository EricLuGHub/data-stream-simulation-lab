# Data Stream Simulation Lab

An event-driven simulation workspace for processing dense streams of market-like
events, testing stateful strategies, and evaluating outcomes across repeatable
experiments.

The repository contains Python implementations, exploratory analysis, and
experiment artifacts from several simulation rounds. It focuses on the
engineering loop: ingest data, model state, run a bounded experiment, and
inspect the result.

## Stack

Python, NumPy, pandas, Jupyter

## Run

```sh
pip install -r requirements.txt
```

Individual experiment folders contain their corresponding scripts and notes.
